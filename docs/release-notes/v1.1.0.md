## LiveWall 1.1.0

**New**
- **Software Update**: LiveWall checks GitHub once a day for a new version (you can turn this off in Settings) and shows what's new. **Update Now** downloads it, checks it and reopens LiveWall on the new version. A red dot on Settings tells you when one is out.
- `livewall://update` checks right away; `livewall://update/install` also installs.

**Fixed**
- Runs on Intel Macs as well as Apple silicon.
- The download is now always called `LiveWall.zip`, and it unzips cleanly with any tool. 1.0.0's zip could arrive "damaged" when unzipped outside Finder.

**Install** (macOS 14+, Apple silicon and Intel). Coming from 1.0.0, which can't update itself, run this once; later versions install from Settings › Software Update:

```bash
curl -fL https://github.com/charonova/LiveWall/releases/latest/download/LiveWall.zip -o /tmp/LiveWall.zip \
  && mkdir -p ~/Applications && ditto -xk /tmp/LiveWall.zip ~/Applications && open ~/Applications/LiveWall.app
```

LiveWall isn't notarized by Apple yet. Installed with the command above, it opens right away. From a browser download, unzip `LiveWall.zip`, move LiveWall to Applications, open it once, then click **Open Anyway** in **System Settings › Privacy & Security**.
